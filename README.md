# ม็อดภาษาไทย 龙胤立志传

ม็อดภาษาไทยสำหรับ **龙胤立志传 (Long Yin Li Zhi Zhuan / ตำนานหลงอิ้น)** แบบพร้อมติดตั้ง รองรับเกมเวอร์ชัน `1.0.12f1` บน Steam

## ดาวน์โหลด

ดาวน์โหลด ZIP รุ่นล่าสุดจากหน้า [Releases](https://github.com/waylanders05/LongYinLiZhiZhuan-Thai-Mod/releases/latest)

## วิธีติดตั้ง

1. ดาวน์โหลด `LongYinLiZhiZhuan_ThaiMod_v1.8.0.zip`
2. แตกไฟล์ ZIP ไว้ที่ใดก็ได้
3. ดับเบิลคลิก `Install.bat`
4. เปิดเกมผ่าน Steam ตามปกติ

ตัวติดตั้งจะค้นหาโฟลเดอร์เกม Steam ให้อัตโนมัติ ติดตั้ง MelonLoader ม็อดแปล พจนานุกรม และฟอนต์ไทยให้ครบในครั้งเดียว การเปิดเกมครั้งแรกอาจใช้เวลา 1–3 นาที

## ถอนการติดตั้ง

ดับเบิลคลิก `Uninstall.bat` ภายในโฟลเดอร์ที่แตกจาก ZIP

## สิ่งที่แปล

- เนื้อเรื่องและบทสนทนา
- เมนู ตัวเลือก และคำอธิบาย
- วิชา ไอเทม สำนัก และชื่อตัวละคร
- บทกวีจีนโบราณ 366 บท
- ฟอนต์ไทยที่ปรับตำแหน่งสระและวรรณยุกต์สำหรับเกม

## หมายเหตุ

- ต้องมีเกมแท้บน Steam
- หาก Steam อัปเดตเกมหรือใช้ Verify integrity ให้เรียก `Install.bat` ซ้ำ
- โปรแกรมป้องกันไวรัสบางตัวอาจแจ้งเตือน MelonLoader ซึ่งเป็น mod loader ที่มาพร้อมแพ็ก
- ม็อดแฟนเมดนี้แจกฟรี ห้ามนำไปขายหรือแจกจ่ายเชิงพาณิชย์
